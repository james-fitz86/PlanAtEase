How It Works

Frontend: A React application deployed at planatease.site. Users interact with trip planning, authentication, and dashboards here. The external API integration (e.g. Google Places) is handled entirely within the frontend, so external requests never touch the backend.

Backend: A Django REST Framework API hosted on Render. It manages authentication, user data, trip creation, and all database operations.

API: The backend exposes JSON endpoints at /api/trips/ and /auth/, consumed by the frontend. These endpoints allow CRUD operations on trips, trip items, and user accounts.
